# ROADSHIELD
### Smarter Insights. Safer Roads.

**ROADSHIELD** is a machine learning-based road safety analytics platform developed using Python and Flask. It analyzes historical UK road collision data (2023–2025) to predict collision severity, explore accident trends, and identify geographical collision hotspots.

## Key Features

- **Severity Prediction:** Predicts collision severity as Fatal, Serious, or Slight using a trained Random Forest Classifier.
- **Analytics Dashboard:** Visualizes collision trends, severity distributions, and patterns across different road conditions.
- **Historical Insights:** Provides statistical insights based on selected collision conditions.
- **Hotspot Detection:** Identifies locations with high concentrations of severe collisions using geospatial analysis and interactive maps.

## Dataset

The project uses approximately **306,710 road collision records from Great Britain (2023–2025)**, containing information about weather, road conditions, lighting, location, time, and collision severity.

## Technologies Used

- **Backend:** Python, Flask
- **Machine Learning:** Scikit-learn, Random Forest
- **Data Analysis:** Pandas, NumPy
- **Visualization:** Chart.js, Folium
- **Frontend:** HTML, CSS, JavaScript
- **Version Control:** Git, GitHub
